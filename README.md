# ועד בית הלוט 43א

אב-טיפוס לממשק ניהול ועד בית בעברית. פתחו `index.html` בדפדפן כדי להתנסות.

**חשוב:** הנתונים נשמרים רק בדפדפן המקומי (`localStorage`). אין בגרסה זו התחברות מאובטחת, גיבוי, סנכרון, ניהול חובות מלא, או שליחת WhatsApp אוטומטית. אין להכניס נתוני דיירים אמיתיים לפני הקמת תשתית מאובטחת.
